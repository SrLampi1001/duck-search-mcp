# Duck Duck Go search MCP
This project objective is to create an MCP that implements the DuckDuckGo free Auth less API with the best possible practices.

The objective is to offer the search tool, that search entities like queries and returns simple results, inclduing the skills and reusable prompts that can be implemented to make sure any AI Agent querying using the MCP get's the most from each search.
